# `.pdraw` 工程文件规范（可编辑项目 JSON）

`.pdraw` 是 **ParticleDrawing 粒子动画编辑器** 保存的可编辑工程文件。它是 JSON 文本
（`application/json`），编辑器用它做「打开 / 保存 / 另存为」，并作为导出播放用
`.pdrawc` 二进制的源数据。

> 播放端专用格式请见 [`docs/pdrawc-format.md`](./pdrawc-format.md)。

---

## 1. 版本

| 版本 | 说明 |
|---|---|
| `v:4` | 旧版工程：无 `key` 字段；内嵌贴图 `texData`（base64 PNG） |
| `v:5` | 旧版工程：新增 `key` 字段（Ed25519 密钥对），用于导出时签名 `.pdrawc` |
| `v:6` | 当前版本：函数对象改为 `setup`/`process`/`seed` 脚本模型 |

当前编辑器**只接受 `v:6`**；旧版本工程会提示「工程版本过旧」并拒绝打开。

---

## 2. 顶层结构

```jsonc
{
  "v": 7,                       // 格式版本，当前固定为 7
  "key": {                      // v5 新增；Ed25519 密钥对
    "alg": "Ed25519",
    "private": "<base64 PKCS#8 DER 私钥>",
    "public": "<base64 32 字节公钥>"
  },
  "loop": true,                 // 是否循环播放
  "g":   { ... },               // 组：组名 -> 粒子 id 数组
  "p":   [ ... ],               // 独立粒子（不含函数对象派生的粒子）
  "t":   [ ... ],               // 分量级轨道
  "f":   [ ... ],               // 函数对象定义
  "tex": [ "a", "b" ],          // 贴图名列表
  "guv": { ... },               // 组级 UV：组名 -> UV 对象
  "gss": { "组A": 1 },          // v7 新增，可选：组级自转空间（1 = local；缺省/0 = world）
  "texData": { ... }            // 可选：贴图名 -> base64 PNG
}
```

- `p` 只包含**非派生粒子**（`!particle.fx`）。
- `t` 只包含**非函数对象轨道**（`!track.fx`）。
- `g` 剔除派生粒子成员（id 形如 `fxId:p<i>`，播放端实时生成）。
- `texData` 仅在内嵌贴图缓存非空时写入。
- 数值写入时四舍五入到 3 位小数（`r3`）；等于默认值的字段省略以减小体积，解析端有默认回退。

## 3. 粒子 `p[]`

```jsonc
{
  "id": "粒子0",                    // 必填，字符串
  "pos": [0.5, 1, -2],              // 必填，[x,y,z]
  "c":   [1, 0.5, 0.25, 1],         // 可选，颜色 [r,g,b,a]，0..1；默认白 [1,1,1,1] 时省略
  "sc":  [2, 2, 2],                 // 可选，缩放 [sx,sy,sz]；默认 [1,1,1] 时省略
  "g":   1,                         // 可选，发光标记；true 时写 1
  "l":   10,                        // 可选，亮度 0..15；0 时省略
  "vel": [0, 0, 0],                 // 可选，速度 [vx,vy,vz]；全 0 时省略
  "uv":  { ... },                   // 可选，粒子级 UV；仅当 uv.texture 存在时写入
  "st":  5,                         // 可选，入场时间 tick；0 时省略
  "ent": { "p": "fade", "d": 5 },   // 可选，入场过渡（当前仅实现 fade）
  "life": 40                        // 可选，寿命 tick；-1（无限）或省略 = 无限
}
```

解析回退：`id` 缺失自动生成；`c→[1,1,1,1]`；`sc` 支持旧格式标量或数组；`vel→[0,0,0]`；
`st→0`；`life` 仅在 `>=0` 时有效，否则 `-1`。

## 4. 轨道 `t[]`

```jsonc
{
  "pr": "pos.x",                          // 属性.分量（见下）
  "ids": ["粒子0", "g:组A", "f:fx0"],     // 轨道作用对象 id 数组
  "kf": [[0, 1.5, 3], [10, 3, [0.25, 0, 0.58, 1]]],  // [tick, 标量值, 缓动]
  "m": "op"                               // 可选；set（默认）或 op（增量）
}
```

### `pr` 编码

| 属性 | 分量 | 合法 `pr` |
|---|---|---|
| `pos` 位置 | `x/y/z` | `pos.x` `pos.y` `pos.z` |
| `rot` 公转 | `x/y/z` | `rot.x` `rot.y` `rot.z` |
| `spin` 自转 | `x/y/z` | `spin.x` `spin.y` `spin.z` |
| `center` 公转中心 | `x/y/z` | `center.x` `center.y` `center.z` |
| `vel` 速度 | `x/y/z` | `vel.x` `vel.y` `vel.z` |
| `col` 颜色 | `r/g/b/a` | `col.r` `col.g` `col.b` `col.a` |
| `scl` 缩放 | `x/y/z` | `scl.x` `scl.y` `scl.z` |

多分量属性用 `属性.分量`；关键帧值一律是**标量**。

### id 前缀约定

- 裸 id（`粒子0`）→ 普通粒子轨道。
- `g:组名` → 组轨道。
- `f:fxId` → 函数对象整体轨道。

### `m` 语义

- `set`（默认，省略）：绝对值覆盖。
- `op`：增量累加；组/函数对象位移（`pos`）默认使用 `op`。

### 缓动编码（`kf[2]`）

- **整数 0..13**：`EASINGS` 预设下标（见 §7）。
- **`-1`**：无缓动（阶跃）——保持前一关键帧值直到下一关键帧。
- **数组 `[x1,y1,x2,y2]`**：自定义三次贝塞尔。
- 默认缓动 `3`（EASE_IN_OUT）。

解析回退：未知 `pr` 属性名 → `pos.x`；`m` 非 `op` → `set`；非法缓动 → `3`。

## 5. 组 `g` 与组级 UV `guv`

```jsonc
{
  "g":   { "组A": ["粒子0", "粒子1"] },
  "guv": { "组A": { /* UV 对象，见 §6 */ } }
}
```

- `g`：组名 → 成员粒子 id 数组（写入时已剔除派生粒子）。
- `guv`：仅当组 UV 的 `texture` 存在时写入。

## 6. 函数对象 `f[]`

```jsonc
{
  "id": "fx0",                  // 必填
  "name": "函数对象",            // 名称
  "center": [0, 0, 0],          // [x,y,z]
  "count": 200,                 // 派生粒子采样数
  "setup": "arr = []; ...",     // setup 代码块（对象初始化一次；空字符串省略式写 ""）
  "process": "x = arr[i]; ...", // process 代码块（每粒子每帧）
  "funcs": "func f(a) { ... }", // 可选，顶层函数定义代码块（script-lang §4；缺省 = ""）
  "seed": 0,                    // 随机种子（整数；rand()/noise 默认使用）
  "vars": {                     // 变量表
    "amp": { "b": 2, "kf": [[0, 2, 3], [20, 4, 3]] }
  },
  "duration": 40,               // 时长 tick
  "step": 5,                    // 采样间隔（编辑器用）
  "st": 0,                      // 可选，入场时间
  "ent": { "p": "fade", "d": 5 },  // 可选，入场过渡
  "preset": "sin",              // 可选，预设 id
  "params": { "amp": 2 },       // 可选，预设参数
  "ui": { ... },                // 可选，拼图编辑器布局（对播放无意义）
  "uv": { ... },                // 可选，函数对象级 UV
  "fm": 1,                      // 可选，fastMath：process 标量数学近似；缺省/0 = 关闭
  "ss": 1                       // v7 新增，可选：自转空间（1 = local；缺省/0 = world）
}
```

- `vars`：`{ 变量名: { b: 数值基值, kf: [[tick,value,easing],...] } }`。
  当前编辑器使用**数值基值 + 关键帧**模型（不再使用表达式字符串）。
- 函数对象脚本语法见 [`script-lang-spec.md`](./script-lang-spec.md)。
- 解析回退：`name→'函数对象'`、`center→[0,0,0]`、`count→30`、`duration→0`、`step→5`、`st→0`、`setup/process/funcs→''`、`seed→0`、`fm→false`、`ss→'world'`。

## 7. UV 对象

出现在 `p[].uv`、`f[].uv`、`guv[组名]`，字段相同：

```jsonc
{
  "texture": "贴图名",       // 贴图名，null/缺省 = 无贴图
  "mode": "animated",        // "static" | "fill" | "animated"
  "texSize": [16, 16],       // 粒子贴图显示尺寸（像素）
  "uvStart": [0, 0],         // UV 起点 [x,y]（像素）
  "uvSize": [16, 16],        // UV 大小 [w,h]（像素）
  "uvStep": [16, 0],         // UV 步长 [x,y]（像素，动画模式）
  "fps": 4,                  // 动画帧率
  "maxFrame": 8,             // 最大帧数；1=自动，>1=用户上限
  "loop": true               // 循环
}
```

- `maxFrame` 语义：`0`/`1`/缺省 = 不限制（自动帧数）；`>1` = 显式上限。
- 生效优先级：**函数对象 `f.uv` > 组 `guv` > 粒子 `p.uv` > 默认（无贴图）**。

## 9. 兼容性摘要

- 解析端保持宽容：缺失字段回退默认值；旧变量格式（`"amp": "2"` 或 `{expr}`）仍可读。
- 加载判定：文件名以 `.pdraw` 结尾、`obj.v >= 2` 或存在 `obj.f` → 完整工程导入；否则按旧 JSON 导入。
